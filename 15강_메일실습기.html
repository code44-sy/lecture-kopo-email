비즈니스 메일 실습기

교수님께 보내는 ‘결석 사전 양해 메일’을 직접 써서 보내봅니다. 연차 신청과 구조가 똑같습니다.

✓

받는 사람 (교수 이메일)

한 번만 입력

선생님이 수업 전에 한 번만 입력해 두면 학생 모두에게 적용됩니다. (이 기기에 저장됩니다)

1

내 정보

본인의 과와 이름을 입력하세요.

2

내 상황 고르기

본인 현실에 맞는 상황을 고르면 제목과 본문이 자동으로 채워집니다. (고른 뒤 자유롭게 수정하세요)

면접 일정과 수업이 겹침
가장 현실적인 상황
국가기술자격 실기시험 응시
응시 종목을 직접 입력
채용박람회 · 현장실습 참가
외부 행사 참가
연차 신청 (직장인 버전)
해당 없을 때 — 미래 연습용
3

제목 — 직접 작성

규칙: [소속] 용건 - 이름

맨 앞에 [실습]을 붙입니다. 안 그러면 교수님이 실제 승인으로 오해할 수 있어요.

교수 메일함에서는 이렇게 보입니다 — ‘제목 줄’
보낸사람제목을 입력하면 여기에 보입니다
4

본문 — 직접 작성

두괄식으로 직접 써 보세요. 순서: 인사 + 소속·이름 → 결론(결석/연차)을 먼저 → 사유 → 후속(보강 문의 / 인수인계) → 감사 → 서명. 아래 ‘5원칙 체크’가 실시간으로 도와줍니다.

★

완성 예시 (참고용)

직접 써본 뒤 비교해 보세요. 그대로 베끼기보다 ‘내 메일과 어디가 다른지’를 찾는 게 핵심입니다.

상황을 먼저 골라주세요.
✓

메일 5원칙 체크

하나씩 켜지면 좋은 메일에 가까워집니다. 다 안 켜져도 괜찮아요 :)

  • !제목이 [실습][소속] 용건 - 이름 형식
  • !첫 줄에 인사 + 소속 · 이름
  • !결론(결석/연차)을 앞쪽에 먼저 (두괄식)
  • !후속 한마디 (보강 문의 / 인수인계)
  • !끝에 서명 (소속 · 이름 · 연락처)
